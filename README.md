# 語詞錄音整理工具 使用說明

**開啟方式**：把「語詞錄音整理工具.html」存到電腦，點兩下用 **Chrome**（Windows、Mac 都可以）打開。第一次錄音請按「允許麥克風」。

1. ① 輸入語詞（一行一個，可不填）；可填「要教的注音符號」，例如 ㄆ。
2. ② 按紅色大圓鈕（或空白鍵）錄音，再按一次停止。
   - 沒先輸入語詞：直接按紅鈕，或勾「自由錄音」。錄完系統會自動辨識你唸的字並標好注音，黃框問你對不對；對就按 Enter，不對就改大字。
3. ④ 按「選擇存放資料夾」選一次，之後確認好的音檔會自動存進去，並依「要教的注音符號」放進子資料夾（沒填就用第一個字的聲符）。
4. 也可以按「下載全部」得到 zip（已分好資料夾，附清單.csv 與 voice-pack.json）。

注意：自動辨識需要連網；Safari 不能直接存進資料夾，請用 Chrome／Edge。

編輯音檔（修剪、音量、去雜訊、音長）：在錄音畫面按「✂️ 編輯」。
